# iCoordinator

اپ اندروید برای برنامه‌ریزی شخصی: پروژه با اهداف و درصد پیشرفت، مانیفست، لاگ هفتگی، روتین‌ها، تقویم و گزارش هفته.

## وضعیت
- **اسپرینت ۰:** اسکلت پروژه (Kotlin + Jetpack Compose + Room)، ناوبری پایه و رابط فارسی راست‌به‌چپ.

## باز کردن در Android Studio
1. Android Studio را اجرا کن و **Open** را بزن.
2. پوشه‌ی `E:\Dev\projects\iCoordinator` را انتخاب کن.
3. اجازه بده Gradle sync انجام شود (در اولین بار Gradle Wrapper و وابستگی‌ها دانلود می‌شوند).
4. دکمه‌ی Run را بزن و گوشی یا Emulator را انتخاب کن.

## ساختار
- `app/src/main/java/com/icoordinator/MainActivity.kt`: نقطه‌ی ورود و تنظیم RTL
- `ui/AppNavHost.kt`: ناوبری و نوار پایین (پنج بخش)
- `ui/theme`: تم برنامه

## اسپرینت‌های بعدی
۱. پروژه، اهداف و مانیفست
۲. لاگ هفتگی و تسک‌ها
۳. تقویم و آلارم
۴. روتین‌ها
۵. گزارش هفته
۶. پایداری، مجوزها و تست
