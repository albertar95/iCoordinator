# Handover: iCoordinator

## خلاصه
اپ اندروید برنامه‌ریزی شخصی با Kotlin، Jetpack Compose و Room. همه‌ی شش اسپرینت پیاده‌سازی شده، اما **کد هنوز در Android Studio کامپایل یا روی گوشی تست نشده است.** اولین کار بعدی باید Sync، Build و تست دستی باشد.

- مسیر پروژه: `E:\Dev\projects\iCoordinator`
- زبان رابط: فارسی، راست‌به‌چپ (RTL)
- حداقل اندروید: 8.0 (API 26)، هدف: API 34
- دیتابیس: Room نسخه ۴
- بدون بک‌آپ و بدون همگام‌سازی ابری (تصمیم تأییدشده)
- نمره‌ی هفته: بالای ۸۰٪ خوب، ۵۰ تا ۸۰٪ متوسط، زیر ۵۰٪ بد

## ساختار پوشه‌ها
```
app/src/main/java/com/icoordinator/
  ICoordinatorApp.kt        نقطه‌ی ورود و ریپازیتوری‌ها (ServiceLocator ساده)
  MainActivity.kt           اجرای Compose و درخواست اجازه‌ی نوتیفیکیشن
  alarm/                    AlarmManager، BroadcastReceiverها و بازنشانی بعد از ری‌استارت
  data/                     AppDatabase، DAOها، entityها و ریپازیتوری‌ها
  domain/                   منطق خالص (درصد، نمره، هفته، روتین) بدون وابستگی به اندروید
  ui/                       صفحه‌ها: projects، weekly، routines، calendar، report
app/src/test/               تست‌های واحد domain و alarm
handover/                   این مستندات
```

## تصمیم‌های کلیدی
1. **درصد پیشرفت پروژه** از جمع درصد اهداف تیک‌خورده محاسبه می‌شود و ذخیره نمی‌شود. مجموع درصد اهداف هر پروژه نمی‌تواند از ۱۰۰ بیشتر شود.
2. **روتین‌ها** با ماسک بیتی روزها (`daysMask`) ذخیره می‌شوند. انجام هر روتین در هر روز جداگانه در `routine_completions` ثبت می‌شود.
3. **آلارم‌ها** با `AlarmManager.setExactAndAllowWhileIdle` ثبت می‌شوند. اگر اجازه‌ی آلارم دقیق نباشد، از حالت تقریبی استفاده می‌شود.
4. **کد درخواست آلارم**: تسک‌ها بیت ۳۰ صفر دارند و روتین‌ها بیت ۳۰ یک دارند تا تداخل نداشته باشند.
5. **حذف پروژه**: تسک‌هایش حذف نمی‌شوند؛ پیوند پروژه‌شان خالی می‌شود (`SET_NULL`). اهداف و تیک‌هایشان با پروژه حذف می‌شوند (`CASCADE`).
6. **گزارش هفته** با متن ثابت فارسی ساخته می‌شود و به اینترنت وابسته نیست.
7. **تاریخ** فعلاً میلادی نمایش داده می‌شود.

## راه‌اندازی برای توسعه‌دهنده‌ی بعدی
1. پوشه‌ی `E:\Dev\projects\iCoordinator` را در Android Studio باز کن.
2. **Sync Project with Gradle Files** را بزن (Gradle Wrapper خودکار ساخته می‌شود).
3. **Run** روی گوشی واقعی یا Emulator.
4. تست‌های واحد: `app/src/test` را با **Run Tests** اجرا کن.
