# Roadmap: مسیر بعدی iCoordinator

این نقشه بر اساس وضعیت فعلی تنظیم شده است. ترتیب موارد اولویت‌بندی شده است.

آخرین به‌روزرسانی: ۱۵ آبان ۱۴۰۵ (۶ نوامبر ۲۰۲۶). اپ با GitHub Actions بیلد و روی گوشی نصب شده و رابط کاربری جدید تأیید شده است. موارد تیک‌خورده انجام شده‌اند.

## فاز ۰: اعتبارسنجی اولیه (قبل از هر کار جدید)
- [x] Build بدون خطا (با GitHub Actions، بیلد روی سیستم محلی انجام نمی‌شود)
- [x] رفع خطاهای کامپایل (احتمالاً Compose compiler و import ها)
- [x] اجرای تست‌های واحد (در GitHub Actions قبل از ساخت APK اجرا می‌شوند)
- [x] نصب و اجرا روی گوشی واقعی
- [ ] بررسی جریان اصلی با چک‌لیست `UI-TEST-GUIDE.md`:
  - ساخت پروژه، هدف، تیک، پیشرفت
  - ساخت تسک، تیک، حذف
  - ساخت روتین، تیک روزانه، حذف
  - تقویم و نقطه‌های هر روز
  - ساخت گزارش هفته
- [ ] تست آلارم تسک و روتین در زمان مقرر
- [ ] تست بازنشانی آلارم بعد از ری‌استارت

## فاز ۱: رفع ریسک‌های اصلی
- [ ] صفحه‌ی راهنمای تنظیمات باتری برای گوشی‌های محدودکننده
- [ ] نمایش هشدار اگر اجازه‌ی نوتیفیکیشن رد شده باشد
- [x] تأیید قبل از حذف پروژه و روتین
- [x] پاک‌کردن خطای ViewModel بعد از نمایش
- [x] تصحیح `ProjectDetailScreen` (گرفتن `return` از داخل `run`)
- [ ] تنظیم `allowBackup` بر اساس تصمیم حریم خصوصی

## فاز ۲: تکمیل ویژگی‌ها
- [ ] ویرایش تسک (عنوان، روز، ساعت، پروژه)
- [ ] ویرایش روتین (عنوان، روزها، ساعت)
- [x] تاریخ شمسی در همه‌ی صفحه‌ها (لاگ هفتگی، تقویم، گزارش)
- [ ] انتخاب هفته‌ی قبلی برای ساخت گزارش
- [ ] نمایش اهداف در نمره‌ی هفته (در صورت تأیید کاربر)
- [x] صفحه‌ی خالی بهتر با راهنمای کوتاه

## فاز ۳: پایداری و کیفیت
- [ ] نوشتن `Migration` برای دیتابیس قبل از هر تغییر ساختار
- [ ] تست instrumented برای DAOها
- [ ] تست UI برای جریان اصلی با Compose testing
- [ ] بررسی کارایی تقویم با داده‌ی زیاد
- [ ] لاگ خطا برای آلارم‌های شکست‌خورده

## فاز ۴: تجربه‌ی کاربری و ظاهر
- [x] بازطراحی کامل رابط کاربری (فونت وزیرمتن، آیکون‌های Tabler، کارت‌ها، نوار پایین جدید، حالت تاریک) - ۱۵ آبان ۱۴۰۵
- [x] آیکون برای ناوبری پایین
- [x] بررسی حالت تاریک و رنگ‌ها
- [ ] نمایش پیشرفت هدف‌ها در تاریخچه‌ی پروژه
- [ ] تنظیمات: زمان پیش‌فرض آلارم، ساعت شروع هفته

## فاز ۵: آماده‌سازی انتشار
- [x] آیکون اپ (حلقه و نقطه، سفید روی سبزآبی)
- [ ] نام نهایی اپ
- [ ] نسخه‌ی release با minify و signing
- [ ] تست روی چند مدل گوشی و اندروید مختلف
- [ ] سیاست حریم خصوصی و بک‌آپ

## آینده (بعد از انتشار، فقط در صورت نیاز)
- بک‌آپ و همگام‌سازی ابری

- خروجی گرفتن از گزارش‌ها
