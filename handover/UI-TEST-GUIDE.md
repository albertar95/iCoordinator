# راهنمای تست رابط کاربری جدید

آخرین به‌روزرسانی: ۱۵ آبان ۱۴۰۵ (۶ نوامبر ۲۰۲۶). اپ نصب شده و ظاهر جدید تأیید شده است. این چک‌لیست برای تست کارکردها با ظاهر جدید است.

## چه چیزی عوض شد
- **تم و رنگ:** سبزآبی با سطح‌های خنثی، روشن و تاریک (`ui/theme/Theme.kt`).
- **فونت:** وزیرمتن با اعداد فارسی (`res/font`).
- **آیکون‌ها:** Tabler به‌صورت فایل‌های `res/drawable/ic_tb_*.xml`.
- **اجزای مشترک:** کارت‌های گرد، دایره‌ی آیکون، دکمه‌های گرد، حالت خالی، دیالوگ تأیید حذف (`ui/components/AppComponents.kt`).
- **نوار پایین** (`ui/AppBottomBar.kt`): از راست پروژه‌ها، روتین‌ها، **تقویم** (دکمه‌ی برجسته‌ی وسط)، تسک‌ها، گزارش هفته.
- «لاگ هفتگی» به **«تسک‌ها»** تغییر نام داد و بالای آن یک بخش رنگی با سلام، بازه‌ی هفته، شمارنده‌ی انجام‌شده و دکمه‌های گرد (تسک جدید، هفته قبل، هفته بعد، فعال‌سازی آلارم) دارد.
- **بنر آلارم** حذف شد؛ دکمه‌ی «فعال‌سازی آلارم» فقط وقتی اجازه نیست در صفحه‌ی تسک‌ها دیده می‌شود.
- **دکمه‌ی «+»** پروژه‌ها و روتین‌ها بالا سمت چپ است (دکمه‌ی شناور پایین حذف شد).
- **همه‌ی حذف‌ها** تأیید می‌خواهند.
- **لوگوی جدید:** حلقه‌ی باز و نقطه، سفید روی سبزآبی.

## چه چیزی عوض نشد (عمداً)
- داده، دیتابیس، دامنه (محاسبات)، آلارم، ViewModelها و فایل‌های build.
- امکان ویرایش تسک و روتین هنوز نیست.

## بیلد و نصب
1. `push.bat` را در ریشه‌ی پروژه اجرا کن.
2. در تب Actions گیت‌هاب منتظر بیلد بمان و فایل `icoordinator-debug-apk` را دانلود کن.
3. APK را روی گوشی نصب کن. اگر لوگو عوض نشد، اپ را حذف و دوباره نصب کن.

## چک‌لیست تست
برای هر مورد: کار کرد / نکرد / نمی‌دانم + یک جمله توضیح.

### ظاهر (تأیید شده در ۱۵ آبان ۱۴۰۵)
- [x] فونت، آیکون‌ها و رنگ‌ها
- [ ] حالت تاریک گوشی
- [ ] متن‌ها و فاصله‌ها روی گوشی کوچک (بدون بریدگی)
- [ ] بخش رنگی بالای صفحه‌ی تسک‌ها زیر نوار وضعیت درست دیده می‌شود

### پروژه‌ها
- [ ] ساخت پروژه با دکمه‌ی «+» بالا، و از دکمه‌ی صفحه‌ی خالی
- [ ] باز کردن پروژه، دیدن درصد پیشرفت و نوار، و برگشت با فلش
- [ ] افزودن هدف با درصد (و پیام خطا وقتی مجموع بیشتر از ۱۰۰ است)
- [ ] پاک شدن خطا بعد از تایپ دوباره
- [ ] تیک زدن هدف و تغییر پیشرفت
- [ ] حذف هدف (باید تأیید بخواهد)
- [ ] ذخیره‌ی مانیفست
- [ ] حذف پروژه (باید تأیید بخواهد) و باقی ماندن تسک‌های آن

### تسک‌ها
- [ ] جابه‌جایی بین هفته‌ها با دکمه‌های گرد
- [ ] افزودن تسک با روز، ساعت، پروژه و آلارم
- [ ] تیک زدن تسک و تغییر شمارنده و نوار
- [ ] حذف تسک (باید تأیید بخواهد)
- [ ] حالت خالی هفته
- [ ] دکمه‌ی «فعال‌سازی آلارم» وقتی اجازه نیست دیده شود، تنظیمات را باز کند، و بعد از دادن اجازه و برگشت پنهان شود

### روتین‌ها
- [ ] ساخت روتین با روزها و ساعت
- [ ] حذف روتین (باید تأیید بخواهد)

### تقویم

- [ ] انتخاب روز و نمایش آیتم‌ها
- [ ] تیک زدن آیتم روز

### گزارش
- [ ] ساخت گزارش هفته‌ی جاری
