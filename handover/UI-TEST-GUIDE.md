# راهنمای تست نسخه‌ی جدید UI

## چه چیزی عوض شد
- تم جدید (رنگ‌های روشن و تاریک، تیرگی سبز‌آبی) در `ui/theme/Theme.kt`.
- کامپوننت‌های مشترک جدید در `ui/components/AppComponents.kt`: کارت، عنوان بخش، حالت خالی، نشان نمره، دیالوگ تأیید حذف، نوار پیشرفت.
- صفحه‌ها: پروژه‌ها و جزئیات پروژه، لاگ هفتگی، روتین‌ها، تقویم، گزارش هفته.
- ناوبری پایین: فقط متن (بدون آیکون) با نشانگر برای بخش فعال (F1).
- بنر آلارم دقیق با ظاهر جدید.
- همه‌ی حذف‌ها (پروژه، هدف، تسک، روتین) حالا اول تأیید می‌خواهند (F3).
- خطای قبلی با تایپ دوباره پاک می‌شود (F6).
- در جزئیات پروژه، `return` داخل `run {}` حذف شد.

## چه چیزی عوض نشد (عمداً)
- داده، دیتابیس، دامنه (محاسبات)، آلارم، ViewModelها و فایل‌های build.
- تاریخ هنوز میلادی است (F2). تاریخ شمسی فاز بعدی است.
- امکان ویرایش تسک و روتین هنوز نیست.

## بیلد
1. پوشه را در Android Studio باز کن و Sync بزن.
2. Build > Make Project. اگر خطا دیدی، متن خطا و اسم فایل را برای من بفرست.
3. اجرا روی گوشی یا Emulator.

> این تغییرات در محیطی که من کار می‌کنم کامپایل نشده‌اند. بررسی‌ها فقط ساختار و امضاها را چک کرده‌اند. اولین Build ممکن است چند خطای کوچک Kotlin بدهد.

## چک‌لیست تست
برای هر مورد: کار کرد / نکرد / نمی‌دانم + یک جمله توضیح.

### پروژه‌ها
- [ ] ساخت پروژه جدید
- [ ] باز کردن پروژه و دیدن درصد پیشرفت و نوار
- [ ] افزودن هدف با وزن (و پیام خطا وقتی مجموع بیشتر از ۱۰۰ است)
- [ ] پاک کردن خطا بعد از تایپ دوباره
- [ ] تیک زدن هدف و تغییر پیشرفت
- [ ] حذف هدف (باید تأیید بخواهد)
- [ ] ذخیره‌ی مانیفست
- [ ] حذف پروژه (باید تأیید بخواهد) و تسک‌های آن بعد از حذف باقی بمانند

### لاگ هفتگی
- [ ] جابه‌جایی بین هفته‌ها
- [ ] افزودن تسک با روز، ساعت، پروژه و آلارم
- [ ] تیک زدن و حذف تسک (حذف باید تأیید بخواهد)
- [ ] حالت خالی هفته

### روتین‌ها
- [ ] ساخت روتین با روزها
- [ ] تیک روزانه
- [ ] حذف روتین (باید تأیید بخواهد)

### تقویم
- [ ] جابه‌جایی ماه
- [ ] انتخاب روز و نمایش آیتم‌ها
- [ ] تیک زدن آیتم روز
- [ ] نشانگر روزهای دارای آیتم

### گزارش
- [ ] ساخت گزارش هفته جاری
- [ ] نمایش نمره با رنگ درست
- [ ] باز کردن متن گزارش

### ناوبری و آلارم
- [ ] جابه‌جایی بین پنج بخش و نشانگر بخش فعال
- [ ] بنر آلارم دقیق (وقتی اجازه نیست)
- [ ] آلارم تسک و روتین در زمان مقرر (هنوز قبلاً تست نشده)
- [ ] بعد از ری‌استارت گوشی آلارم‌ها برمی‌گردند

### ظاهر
- [ ] حالت تاریک گوشی
- [ ] متن‌ها و فاصله‌ها روی گوشی کوچک (بدون بریدگی)

## موارد قبلاً تست‌شده
لطفاً بگو کدام‌ها را قبلاً تست کرده‌ای و نتیجه‌شان چه بود؛ من با `handover/findings.md` مقایسه می‌کنم.
